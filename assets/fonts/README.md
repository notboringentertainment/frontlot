# Trailer title faces

Source Serif is the clean serif choice. Source Sans is the clean sans-serif choice. Both supplied files are the publishers’ unchanged semibold faces. They are bundled, not installed into the operating system. Patrick Hand remains available from the existing app assets.

Each new face is licensed under the SIL Open Font License. That licence permits use in lettering and redistribution with the application when its copyright notice and licence accompany the font. It does not put the font’s licence on a film made with it. The reserved name is preserved because these are unchanged original files. The complete licence text is beside each font.
