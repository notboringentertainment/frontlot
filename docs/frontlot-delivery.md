# A final trailer file the writer can approve

The writer reviews a saved cut, signs that exact rough-cut revision, makes a local final file, watches it and signs that exact file. The automatic measurements and the writer's signature remain separate. A signature never approves a later edit or different bytes. Nothing is sent or spent.

The existing timeline renderer is shared between preview and final output. Final lettering is drawn from the same literal words, font and layout at three times the preview resolution. Neither path wraps, rewrites or shrinks words. The existing licensed faces stay bound to the signed cards.

Each export has its own folder. Work files remain visibly separate until the render, measurements and input checks finish. Publication exposes only a complete checked file and a committed record. Previous files and edit revisions remain intact after failure. The writer can reveal a currently approved file in Finder.

Rough-cut signing shows playback with the saved colour and sound settings. A newer before comparison is never used as its review movie. If finished playback or its matching settings cannot be verified, the screen asks the writer to prepare it again before signing.

The existing artifact-review gate signs rough-cut and final records. The signer constructs them from current files and checks again at signature time. Existing checkpoint prerequisites remain binding. A valid file approval is not a substitute for missing earlier stage approvals; a checkpoint that cannot advance stays unfinished, with a plain explanation.

The existing signed generation receipt also seals the local render record. This is evidence of what the local renderer produced, not the writer's approval. It prevents an edited report from relabelling an old movie as a newly signed cut. Final signing still independently measures the actual movie; neither receipt substitutes for that check or for the writer's signature.
